# AI-Assisted Assessment of Medial Meniscus Thickness and Patient-Specific Knee Implant Sizing

## 📌 Problem Statement

Knee osteoarthritis is a common degenerative joint condition that can cause pain, stiffness and reduced mobility.

This project aims to develop an AI-assisted system that analyzes knee MRI images to assess the medial meniscus thickness and provide patient-specific information that can assist in knee implant sizing.

## 🎯 Objectives

- Process and analyze knee MRI images.
- Identify the medial meniscus region.
- Estimate medial meniscus thickness.
- Extract relevant patient and image features.
- Develop an AI/ML model for patient-specific analysis.
- Provide an estimated implant size as a decision-support output.
